Calm Reader

Clean reading view for Chrome

Read anything, distraction-free.

Mercury Reader is gone. Calm fills the gap — the same clean reading experience, open-source, zero data collection.

  • Strips ads, navigation, sidebars, and popups from any article
  • Light, Sepia, and Dark themes with one click
  • Adjustable font size and family (Serif, Sans, Mono)
  • Powered by Mozilla Readability — the same parser Firefox uses
  • Zero data collection, zero remote code, zero backend
  • Works with keyboard shortcut Alt+R
